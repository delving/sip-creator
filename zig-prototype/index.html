SIP-Creator WASM Prototype

High-performance cultural heritage metadata transformation engine built with Zig

About This Project

This is a WebAssembly (WASM) implementation of the SIP-Creator mapping engine, originally written in Java/Groovy. The goal is to create a fast, portable metadata transformation engine that can run in browsers, edge workers, and embedded systems while maintaining compatibility with existing SIP-Creator mapping files.

The engine transforms cultural heritage metadata from formats like LIDO (used by museums) to EDM (Europeana Data Model), enabling interoperability between different cultural heritage systems.

✨ Implemented Features

  • String Functions - Replace, replaceAll, capitalize, split, trim, case conversion
  • XML Parsing - Full XML parsing with namespace support
  • SIP-Creator Navigation - Path-based navigation with underscore suffix for "first non-empty"
  • String Interpolation - Template variables with ${variable} syntax
  • EDM XML Generation - Generate valid Europeana Data Model output
  • Mapping Processor - Transform LIDO to EDM with configurable rules
  • UTF-8 Support - Proper handling of international characters
  • Memory Safe - Fixed 2MB heap with bounds checking

🔧 Technical Details

Language: Zig 0.14.0-dev

Target: WebAssembly (wasm32-freestanding)

Module Size: 44KB (includes all features)

Memory: 2MB fixed heap, 64KB string buffers

Build: zig build wasm

Architecture: Single-threaded, zero dependencies, no dynamic allocation

🚧 Pending Features
